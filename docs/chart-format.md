# 谱面格式

谱面是一段纯文本。一首歌由**头信息**、**段落**和**小节**组成。

```text
title: 六根弦的夜
key: C
capo: 2
bpm: 76
beats: 4

## 主歌
rh: B 3 2 3 1 3 2 3
| 夜:0.5 里:0.5 | [C]的:1.5 窗:0.5 台:1.5 亮:0.5 | [G]着:1 一:0.5 盏:0.5 灯:2 |

## 副歌
rh: D---D-DUD---D-DU
| [F]*:1 *:0.5 *:1 *:0.5 *:1 | [G]*:0.5 *:1 [E7@3]*:0.5 *:1 *:1 {R-------} |
```

`//` 开头的行是注释。

## 头信息

| 字段 | 含义 |
|---|---|
| `title:` | 歌名 |
| `key:` | 调，只用来显示，例如 `#C`、`C（原调 D）` |
| `source:` | 谱的来源或转写者，显示在歌名下面 |
| `capo:` | 变调夹品位。和弦按指法名写，伴奏和麦克风判定会自动加上变调夹 |
| `bpm:` | 原曲速度（练习时可以在页面上调） |
| `beats:` | 每小节拍数（3/4 拍写 3）。写在小节之间可以中途变拍号，之后的小节都按新拍号，直到再次改回来 |

## 段落

`## 段落名` 开始一个新段落，例如 `## 主歌1`、`## 副歌`。段落名会显示在页面上，也用来分块填歌词（见下文）。

## 小节

一行里用 `|` 分隔小节，一行可以写多个小节，换行只影响编辑时的阅读。

小节里是一串**音节**，每个写成 `内容:时值`：

| 写法 | 含义 |
|---|---|
| `夜:0.5` | 唱一个字，时值 0.5 拍（八分音符） |
| `*:0.5` | 歌词空位，由使用者粘贴的歌词按顺序填进来 |
| `_:1` | 休止 1 拍 |
| `-:2` | 延长上一个字 2 拍（连线、拖腔，可以跨小节） |
| `啊:1.5` | 直接写出的字（哼唱、衬词） |

时值以拍为单位：`1` 四分，`0.5` 八分，`0.25` 十六分，`1.5` 附点四分，`0.75` 附点八分，`1/3` 三连音。一个小节的时值加起来必须等于拍数，不对的话编辑器里会标红，`scripts/check-charts.mjs` 也会报错。

**第一小节**如果不满拍，会被当成弱起，自动靠右对齐。

## 和弦

| 写法 | 含义 |
|---|---|
| `[C]夜:1` | 和弦在后面这个字的起点换 |
| `[G@3]` | 在本小节第 3 拍换，可以写在小节里任何位置，也可以落在一个字的中间。`@2.5` 是第 2 拍后半拍 |

和弦名按指法写（变调夹之后的指法），`#C`、`♭B` 会自动规范成 `C#`、`Bb`。指法图来自 `src/chart.js` 里的 `CHORDS` 表（6 位字符串，从 6 弦到 1 弦，`x` 表示不弹），缺的和弦加进去即可。

## 右手节奏型

`rh:` 写在段落里，对之后的小节生效，直到下一个 `rh:`。某个小节需要不一样的，在小节里写 `{…}` 只覆盖这一小节。

每个记号占一格，格数决定时值：一小节 8 格是八分音符，16 格是十六分。记号可以用空格分开，扫弦型也可以连写（`D---D-DU`）。

| 记号 | 含义 | 键盘 |
|---|---|---|
| `B` | 当前和弦的根音（自动找对的弦） | 空格 |
| `4` `5` `6` | 拇指弹的低音弦 | 空格 |
| `3` `2` `1` | 3/2/1 弦 | J / K / L |
| `1f3` | 指定弦和品位：1 弦 3 品（旋律、前奏） | 按弦对应 |
| `D` / `U` | 下扫 / 上扫 | F / J |
| `R` | 慢扫琶音 | F |
| `X` | 切音 | F |
| `T` | 击弦（打板） | F |
| `-` | 空 | |
| `B+1` | 同时弹（捏弦） | 两个键一起 |

例：`B - 3 2 T 1 3 2 B - 3 2 T 1 3 2`：拇指根音，3、2 弦，第 2 拍正拍击弦，紧接 1 弦，再 3、2 弦，后半小节重复。

## 歌词怎么填

页面上的歌词框里粘贴歌词，按演唱顺序依次填进谱面里的 `*`，标点和空格会被忽略，括号里的和声会被跳过。也可以用 `## 段落名` 分块，只填同名段落：`## 副歌` 会填所有以“副歌”开头的段落（副歌1、副歌2…），更具体的名字优先。

## 简写

不写时值的小节会按和弦平均分，适合只想快速记个和弦进行：

```text
| [C]夜里的窗台 | [G]亮着一盏灯 [D@3]啊 |
```
