# 从吉他谱转换成谱面

常见的中文弹唱谱（和弦图 + 六线谱 + 简谱 + 歌词）可以按这个固定流程转换。手动转或者交给 AI 助手转都按这个步骤；交给助手时，可以把本文件和 [chart-format.md](chart-format.md) 一起附上。

## 0. 版权

已发行的歌：谱面里**不写歌词、不写旋律音高**，每个要唱的字写成 `*`。歌词由使用者自己粘贴。只有哼唱的“啊”这类衬词可以直接写出。从版权谱上扒下来的谱面放在 `src/songs.private.js` 自己用，不要提交到公开仓库。

## 1. 头信息

- `title:` 歌名；`key:` 来自“1=#C”或“选调：C”；`capo:` 来自“变调夹 N 品”；`beats:` 来自拍号分子。
- 谱上一般没有速度，按原曲慢一点估一个（70 左右），并说明是估的。
- 和弦按谱上的指法名写。

## 2. 结构和反复：全部展开

1. 给每一页的每个小节编号，标出反复记号 `|: :|`、一房二房、D.S./Coda、跳转，以及每遍对应哪一行歌词。
2. 按实际演奏顺序线性写出来：前奏 → 主歌1（第一行歌词）→ 副歌（一房）→ 主歌2（第二行歌词）→ 副歌（二房）…
3. 段落命名用 前奏、主歌1、主歌2、副歌1…、桥段、间奏、哼唱、结束句、尾奏。带编号的名字方便用 `## 副歌` 一次填所有副歌。
4. 谱上中途变拍号（例如插一个 2/4 小节）：在那个小节前写 `beats: 2`，之后写 `beats: 4` 改回来。

## 3. 每个字的节奏

最可靠的办法是**按横向位置对齐六线谱**：简谱和六线谱上下对齐排版，每个字的起点就是它正上方六线谱音符所在的十六分格。先从六线谱的符干和符尾数出每拍的十六分位置，再把简谱的每个音对到最近的格上。

简谱本身的规则用来核对：

- 不带下划线 = 1 拍；一条下划线 = 0.5；两条 = 0.25；后面带点 ×1.5；每个 `–` 加 1 拍；`0` 是休止。
- 同音之间的弧线是**延音线**：一个音，一个字，时值相加。不同音之间的弧线是**圆滑线**：一个字唱几个音，时值相加。
- 从上一小节连过来的音写 `-:时值`；新的字写 `*:时值`；休止写 `_:时值`。
- 两段歌词在同一小节字数不同时，展开后分别写。
- 每小节加起来必须等于拍数（第一小节的弱起除外）。

## 4. 和弦位置

- 按和弦图在小节里的横向位置：前半小节 = 第 1 拍，后半 = 第 3 拍（4/4）。一个小节三个和弦时按位置细读。
- 和弦在某个字的起点换就写在那个字前面 `[G]*:1`；落在字中间就用 `[G@3]`。
- 规范名字：`#Cm7-5` → `C#m7-5`，`♭Bsus2` → `Bbsus2`，`#F` → `F#`。
- 确认每个和弦都在 `src/chart.js` 的 `CHORDS` 里，缺的按谱上的指法图补上（6 弦 → 1 弦，带品位标记的是起始品）。

## 5. 右手

- **分解（六线谱上的 x）**：按 x 所在的线读弦号（最上面一条是 1 弦），按符干/符尾读时值。根音写 `B`，其他拇指音写 `4/5/6`，高音弦写 `3/2/1`，空格写 `-`。
- **扫弦（箭头）**：注意中文谱的箭头方向是按六线谱画的：**向上的箭头是下扫 `D`，向下的箭头是上扫 `U`**。波浪线是琶音 `R`，切音 `X`。
- **击弦（`*` 标记）**：`*` 标在哪根符干上方，击弦就在那个位置，通常是第 2、4 拍正拍。那根符干下面如果是延音线连过来的音，就用 `T` 替换掉；后面紧接的弹弦照常写。
- **前奏/尾奏的旋律**：用 `弦号f品位` 写具体的音，例如 `1f3+5f3 - - 1f0`。
- 每个段落开头都写一次 `rh:`；乐句结尾的单个小节变化用 `{…}` 覆盖，例如一下慢扫加休止 `{D---D-DUR-------}`。
- 读不准的地方在交付时说明。

## 6. 校验

```bash
node scripts/check-charts.mjs 我的歌.txt
```

确认：没有拍数错误、没有缺指法的和弦、每段的歌词空位数和谱上的字数一致。然后在页面里导入，跟着示范听一遍。
